📖 Setup Instructions
  1. Go to script.google.com → New project
  2. Delete the default code and paste the entire miniature_painting_course.gs file
  3. Click Run → run function → setup (first time only) → authorise when prompted
  4. Click Deploy → New deployment
  5. Type: Web app | Execute as: Me | Access: Anyone
  6. Click Deploy → copy the Web App URL
  7. Paste the URL into the box at the top of this page → Save URL
  8. The PWA will now connect to your Apps Script and show live course status
  9. Install as PWA: In your browser, tap the share button → Add to Home Screen
